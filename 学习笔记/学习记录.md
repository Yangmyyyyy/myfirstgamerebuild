## Day05 · 2026-11-01 · 函数（已结束）

- 函数封装：把操作写入有名字的代码块，通过调用执行；不是单纯起别名，内部可以包含多条操作。
- 定义与调用：`void DrawPlayer(Rectangle player) { DrawRectangleRec(player, BLUE); }`；main 绘制阶段调用 `DrawPlayer(player);`。已完成代码检查。
- void：函数不返回值，但仍可以绘制画面等产生效果。不是不执行操作。
- 参数：`Rectangle player` 提供矩形的位置和大小，`Color color` 提供颜色。调用时传入的数据与形参对应。
- 多参数调用：`DrawPlayer(player, RED);`。已完成代码检查。
- 函数复用：同一个函数传入不同颜色，在房间1画蓝色，在房间2画红色。用户已运行确认颜色改变。
- 执行流程：从调用处进入函数，函数结束后回到调用处继续执行。
- 易错点：只修改 main 中的调用，不要将函数内部绘制语句也改成调用自身，否则本例会无限递归。仅介绍递归风险，未正式学习递归。
- bool 返回值：`CheckCollisionRecs(player, door)` 返回是否重叠，赋给 bool 变量。已介绍。
- int 与 return：`int Add(int a, int b) { return a + b; }`，`int result = Add(3, 5);`。用户回答8，正确。
